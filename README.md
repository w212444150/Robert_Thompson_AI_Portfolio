## Problem Statement

Identify a real-world NLP application and explain how it works using course concepts. Describe the NLP tasks the system performs and connect them to techniques covered in class.

## Approach

Selected military command and control AI systems as the topic. Analyzed three core NLP functions these systems perform: voice command recognition, written intelligence summarization, and threat identification from unstructured text.

## Key Points

- Voice recognition converts spoken officer commands into machine actions without stopping to type
- NLP parses commands like "scan that area" or "identify that contact" into discrete system instructions
- Summarization extracts key details from incoming reports and briefings so officers get the critical points fast
- Systems like these are deployed today by the U.S. military and allied forces

## Learning Outcomes

- NLP applications span far beyond commercial chatbots
- Military C2 systems use the same NLP building blocks taught in class: tokenization, NER, summarization
- Domain-specific vocabulary (military terminology, call signs, grid coordinates) requires custom preprocessing
